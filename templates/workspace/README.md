# __WORKSPACE_TITLE__

This is a Docxcelerate document workspace.

__SAMPLE_NOTE__

Start the preview:

```sh
npm run dev
```

Create a document:

```sh
dxcl document new
```

Generate a node:

```sh
dxcl document node
```

Add shared runtime values for a document in its `derivers/index.ts` file.

Type-check documents:

```sh
npm run documents:check
```
