El paquete distribuye salida compilada con declaraciones de tipos. Todos los
puntos de entrada de abajo están declarados en `exports`, así que se resuelven en
Node y en los bundlers sin necesidad de importar en profundidad dentro de
`dist/`.

## docxcelerate

La superficie principal: el compilador de documentos, los helpers de
artefactos, los derivadores, los tipos de runtime y todos los tipos del dominio del
documento.

```ts
import {
  buildDocument,
  buildProjectPreviewDocument,
  cleanMinimalDocumentStyle,
  dataRef,
  derive,
  type DocumentModel,
  type ParagraphNode,
} from "docxcelerate";
```

## docxcelerate/document

La definición de un proyecto de documento — el punto de entrada que usa un
`document.project.ts` generado. La CLI y los nombres de archivo generados siguen
diciendo `document`; la API, no.

```ts
import { defineDocumentProject } from "docxcelerate/document";
```

## docxcelerate/template

La superficie de autoría: los elementos, los hooks y `template` mismo. Esto es
lo que importa un archivo de componente.

```ts
import {
  Document,
  Graph,
  Image,
  Paragraph,
  Section,
  TableOfContents,
  template,
  useAvailableTokens,
  useFormat,
  usePlaceholderData,
  useSetPlaceholders,
  useSetPrompts,
  useShared,
  useState,
} from "docxcelerate/template";
```

Cada nombre de elemento es también un tipo de componente, de modo que `const
Greeting: Paragraph = () => <Paragraph … />` nombra lo que produce un componente
y rechaza devolver el tipo equivocado.

Su runtime de JSX está expuesto en `docxcelerate/template/jsx-runtime` (y
`.../jsx-dev-runtime`), que es a donde resuelve `jsxImportSource`.

## docxcelerate/renderer

Renderizadores que convierten un `DocumentModel` en algo visualizable.

```ts
import { renderDocumentWebsite } from "docxcelerate/renderer";
```

`renderDocumentWebsite` devuelve un **documento HTML completo e independiente**,
con su propio `<html>` y su propio `<style>`, en vez de un fragmento. Insértalo en
un iframe si lo necesitas dentro de otra página; así funciona la vista previa de
la página de inicio de este sitio.

## docxcelerate/docx

Construcción de DOCX.

```ts
import { createDocxDocument } from "docxcelerate/docx";
```

## docxcelerate/scaffold y /cli

El generador de workspaces y su interfaz de línea de comandos, para construir tus
propias herramientas encima.

```ts
import { scaffoldWorkspace } from "docxcelerate/scaffold";
```
