## Deklariert, nicht gezeichnet

Ein Graph-Node enthält Zahlen und eine Form, nie ein Bild:

```tsx
export const VisitsByMonth: Graph = () => {
  const [state] = useState((data: MemberData) => ({
    months: data.visitsByMonth.map((entry) => entry.month),
    visits: data.visitsByMonth.map((entry) => entry.visits),
  }));

  return (
    <Graph
      id="visits-by-month"
      title="Visits by month"
      graphType="bar"
      valueAxisTitle="Visits"
      data={{
        categories: state.months,
        series: [{ label: "Visits", values: state.visits }],
      }}
      caption="Your visits, last six months"
    />
  );
};
```

Was in der `.docx` landet, ist ein **echtes Word-Diagramm** — ein
DrawingML-Chart-Part mit allen Werten darin, samt der Arbeitsmappe, die „Daten
bearbeiten“ öffnet. Der Leser kann es auswählen, umgestalten, seinen Typ ändern
und seine Zahlen öffnen, und Word zeichnet es als Vektoren in jeder Größe.
Nichts davon wird gerastert.

## Die Form der Daten

`data` ist typisiert: Kategorien und Serien, jede Serie mit einem Label, ihren
Werten und optional einer Farbe.

```ts
interface GraphData {
  categories?: string[];
  series: Array<{ label?: string; values: (number | null)[]; color?: string }>;
}
```

`null` ist eine Lücke, keine Null. Ein Monat, der noch nicht abgelesen wurde,
ist kein Monat, in dem nichts gemessen wurde — Word lässt den Punkt aus, statt
die Linie abstürzen zu lassen.

Farben kommen aus dem Theme (`palette.series`, eine feste, auf
Farbfehlsichtigkeit geprüfte Reihe), damit ein Dokument neu gestaltet werden
kann, ohne dass seine Diagramme dazu nicht mehr passen.

Eines geschieht mit den Daten doch: String-Werte laufen durch den
Template-Renderer, genau wie Prosa. Ein Label mit `{{derived.total}}` wird
aufgelöst.

## Ableiten im State

Laufende Summen, Prozentwerte und Umbasierungen gehören in die `data`-Funktion,
nicht weiter stromaufwärts. Diagramm und der Text daneben werden dann aus einer
Quelle berechnet und können sich nicht widersprechen.

## Anmerkungen

- `graphType` steht bei beiden Helpern standardmäßig auf `bar`.
- Bei einem dynamischen Graph liegt die Form weiterhin lokal fest. Der Endpoint
  liefert die Zahlen und darf `graphType` und `caption` in seiner Antwort
  überschreiben.
