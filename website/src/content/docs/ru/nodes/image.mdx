## Каждое поле — это проп

`src`, `alt`, `width`, `height`, `align` и `href` принимают либо обычное значение,
либо функцию от ваших данных. Подпись, различающаяся по офисам, логотип для каждого бренда,
фотография по номеру дела — всё это остаётся внутри узла, а не превращается в
ветвление в шаблоне:

```tsx
export const Signature: Image = () => {
  const [state] = useState((data: MemberData) => ({
    src: data.signatureUrl,
    manager: data.managerName,
  }));

  return (
    <Image id="signature" src={state.src} alt={`Signed by ${state.manager}`} width={180} />
  );
};
```

## src становится path

Опция называется `src`; в разрешённом узле она называется `path`. Разверните
*Во что это разрешается* у первого варианта ниже, чтобы увидеть это.

## Размер и положение

Задайте одну сторону, и другая подстроится под собственные пропорции картинки,
прочитанные из PNG, JPEG, GIF или BMP, которые она несёт (у SVG — из его
`fallbackSrc`): `<Image src={logo} width={160} />` — это логотип шириной 160pt в
его настоящей форме, а не квадрат. Без обеих сторон ширина 120pt; с обеими
получается заданный вами прямоугольник. Картинка, у которой ещё нет байтов, —
URL или промпт, на который ещё не ответили, — резервирует квадрат.

`align="center"` или `"right"` сдвигает строку самой картинки поперёк колонки.
Ничего не обтекает её и не плавает. В ячейке или фигуре действует выравнивание
колонки или фигуры.

## Картинка со ссылкой

`href` заставляет картинку открывать адрес — QR-код, кнопку «Оплатить», логотип —
по Ctrl+щелчку в Word и по щелчку в предпросмотре. Допустимы те же четыре схемы,
что и у [ссылки в `<Text>`](/ru/docs/nodes/paragraph/#слова-набранные-иначе);
всё остальное рисуется картинкой без ссылки, потому что адрес может прийти из
ваших данных. Её `alt` — то, что объявит программа чтения с экрана, поэтому
скажите, куда она ведёт:

```tsx
<Image src={state.qr} alt="Pay invoice 1042 online" width={96} align="right" href={state.payUrl} />
```

## Динамические изображения

Динамическое изображение описывается, а не передаётся, и принимает те же слоты
промптов, что и динамический абзац.

Именно здесь `negativePrompt` оправдывает себя как нигде. Сгенерированные
изображения портятся предсказуемо — впечатанный текст, выдуманные логотипы,
узнаваемые лица, — и этот слот исключает всё это один раз, прямо в узле.

## Примечания

- **Переносится только `data:`-URI.** Он несёт байты, поэтому документ,
  написанный движком в другом месте, всё ещё содержит картинку. Путь или
  http-адрес рисуется на экране, где браузер может его загрузить, но в `.docx`
  попадает лишь заметкой: при упаковке ничего не загружается и не читается с
  диска — машина, которая пишет документ, не та, где лежал файл.
- Word не встраивает SVG сам по себе: дайте растр через `fallbackSrc`. Экран
  рисует SVG, а файл Word получает растр.
- `alt` стоит написать в любом случае: он описывает картинку в файле Word и
  печатается вместо узла, у которого картинки ещё нет.
